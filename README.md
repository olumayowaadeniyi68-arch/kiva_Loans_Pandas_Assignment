## Dataset

This analysis uses `kiva_loans.csv` from the Kaggle dataset:
https://www.kaggle.com/datasets/kiva/data-science-for-good-kiva-crowdfunding

The CSV is not included in this repository. To run the notebook in Colab,
download and extract the dataset, then upload `kiva_loans.csv` using
Colab's Files panel before running the analysis cells.
